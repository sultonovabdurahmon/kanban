# Нақшаи мухтасари техникӣ: Kanban

## 1. Таъинот
Сомона барои идоракунии вазифаҳои даста дар шакли тахтаи канбан: лоиҳаҳо, сутунҳо, корти вазифа бо иҷрокунанда ва мӯҳлат. Он иҷрои вазифаҳоро шаффоф мекунад ва таърихи ҳар тағйиротро нигоҳ медорад.

## 2. Корбарон
- **manager** (роҳбари лоиҳа) — лоиҳа, сутунҳо ва вазифаҳо месозад, иштирокчиёнро илова мекунад.
- **member** (иштирокчӣ) — вазифаҳои худро мебинад, онҳоро мекашад, шарҳ менависад.

(Нақш ба лоиҳа вобаста аст; ниг. `01-domain-analysis.md`.)

## 4. Ҳикояҳои корбарон

**US-01 (ФТ-06).** Ҳамчун иштирокчӣ (member), мехоҳам корти худро ба сутуни дигар кашам, то ҳолати кори худро зуд нишон диҳам.
- Дано: корти ман дар «Барои иҷро» аст. Когда: онро ба «Дар иҷро» мекашам. Тогда: корт бе навсозии саҳифа ҷой иваз мекунад ва пас аз F5 дар ҳамон ҷо мемонад.
- Дано: сервер хато бармегардонад. Когда: корт мекашам. Тогда: паёми хато нишон дода мешавад, корт ба ҷои пештара бармегардад.

**US-02 (ФТ-04).** Ҳамчун роҳбар (manager), мехоҳам вазифа созам ва ба касе таъин кунам, то масъулият аниқ бошад.
- Дано: ман дар лоиҳа роҳбарам. Когда: ном, иҷрокунанда ва мӯҳлатро пур карда «Сохтан»-ро мезанам. Тогда: корт дар «Барои иҷро» бо номи иҷрокунанда пайдо мешавад.
- Когда: номро холӣ мемонам. Тогда: паёми хато ва вазифа сохта намешавад.

**US-03 (ФТ-02).** Ҳамчун роҳбар (manager), мехоҳам иштирокчиро бо email илова кунам, то даста дар як ҷо кор кунад.
- Дано: корбар сабти ном шудааст. Когда: email-и ӯро ворид мекунам. Тогда: ӯ дар рӯйхати иҷрокунандагон пайдо мешавад.
- Когда: email-и номаълум ворид мекунам. Тогда: паём «Корбар ёфт нашуд».

**US-04 (ФТ-05).** Ҳамчун иштирокчӣ (member), мехоҳам танҳо вазифаҳои худро бинам, то аз корти бегона парешон нашавам.
- Дано: ба ман 2 вазифа, ба дигаре 1 вазифа таъин шудааст. Когда: тахтаро мекушоям. Тогда: танҳо 2 корт намоён аст.
- Когда: ба вазифаи бегона дархост мефиристам. Тогда: сервер 403 бармегардонад.

**US-05 (ФТ-07).** Ҳамчун роҳбар (manager), мехоҳам таърихи вазифаро бинам, то фаҳмам кӣ ва кай чиро иваз кардааст.
- Дано: иштирокчӣ корти худро ба «Иҷрошуда» кашид. Когда: корти онро мекушоям. Тогда: дар таърих сатри «кӣ, кай, сутун: Дар иҷро → Иҷрошуда» ҳаст.
- Когда: мӯҳлати вазифаро таҳрир мекунам. Тогда: сатри нав бо қимати кӯҳна ва нав илова мешавад.

## 5. Талаботи ғайрифунксионалӣ

| ID | Талабот | Чӣ тавр санҷида мешавад |
|---|---|---|
| НФТ-01 | Тахта бо 100 вазифа дар ≤ 1 с кушода мешавад | DevTools → Network |
| НФТ-02 | Ҷавоби сервер ба кашидани корт ≤ 500 мс | DevTools → `task_move` |
| НФТ-03 | Паролҳо танҳо ҳамчун ҳеш (`password_hash`) нигоҳ дошта мешаванд | ҷадвали `users` |
| НФТ-04 | Матни кириллӣ (тоҷикӣ, русӣ) дар UTF-8 бе таҳриф нигоҳ дошта мешавад | ворид кардани «Султонов Абдураҳмон», захира, кушодан |
| НФТ-05 | Ҳимоя аз SQL-инъексия (PDO) ва XSS (экранкунӣ); ҳуқуқҳо дар сервер санҷида мешаванд | `<script>` дар ном; дархост ба вазифаи бегона |
| НФТ-06 | Файли замима ≤ 5 МБ, танҳо намудҳои иҷозатдода | боркунии файли 6 МБ → хато |
| НФТ-07 | Стек: PHP 8.2+, MySQL/MariaDB, JavaScript бе фреймворк | `phpinfo()`, `schema.sql` |
| НФТ-08 | Chrome, Firefox, Edge (2 версияи охирин), экран ≥ 1024 px | кушодан дар се браузер |

## 6. MVP
ФТ-01…ФТ-08: сабти ном ва нақшҳо; лоиҳа ва иштирокчиён; сутунҳо; корти вазифа; тахта бо дастрасии мувофиқ; кашидани корт бе навсозӣ; таърихи тағйирот; шарҳҳо.

## 7. Берун аз ҳудуди лоиҳа
- Огоҳиномаҳо, ҳисоби вақт ва ҳисоботи самаранокӣ (ФТ-13, ФТ-14).
- Барномаи мобилӣ ва кашидан бо ламс.
- Ҳамоҳангсозии зинда байни корбарон (WebSocket) ва нақшҳои иловагӣ.
